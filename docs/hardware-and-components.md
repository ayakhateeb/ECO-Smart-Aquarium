# Hardware and Components

This document lists the hardware components reported for the ECO Smart Aquarium prototype.

| Component | Intended role |
|---|---|
| ESP32 | Main microcontroller and Wi-Fi connectivity |
| DS18B20 temperature sensor | Temperature sensing |
| pH sensor | pH measurement |
| TDS sensor | Total dissolved solids measurement |
| Ultrasonic sensor | Water-level estimation |
| LCD 20x4 | Local information display |
| DS1307 RTC module | Real-time clock and scheduling |
| Servo motor | Fish-feeding mechanism |
| Water pumps | Water circulation / refill / drainage functions, as implemented |
| Relay modules | Switching connected loads |

## Software and Services

- Arduino IDE
- C/C++
- Firebase Realtime Database
- Wi-Fi
- Arduino libraries
