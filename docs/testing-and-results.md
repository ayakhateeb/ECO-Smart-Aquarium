# Testing and Results

## Current Status

This document is a placeholder for the team's verified test procedures and results. No quantitative performance results are claimed here.

## Test Areas to Document

| Area | Example verification |
|---|---|
| Temperature sensing | Compare readings with a trusted reference thermometer |
| pH sensing | Calibrate with appropriate buffer solutions and record readings |
| TDS sensing | Verify calibration and compare against a reference meter |
| Water-level sensing | Check measured distance at known water levels |
| Feeding mechanism | Verify scheduled and manual servo operation |
| Lighting | Verify automatic schedule and manual control |
| Pump control | Verify each pump's intended operation and interlocks |
| Firebase communication | Verify successful uploads and remote commands |
| Alerts | Verify alert conditions and audible indication |

## Results Template

For each test, record:

- Test ID and date
- Hardware and firmware version
- Preconditions and setup
- Test steps
- Expected result
- Actual result
- Pass / Fail
- Evidence (photo, screenshot, or measurement log)
- Notes and corrective actions

## Important

Only add measured values, screenshots, and conclusions that are supported by the team's actual testing records. Sensor calibration, electrical safety, and water-resistant installation should be reviewed before presenting the prototype as ready for continuous operation.
